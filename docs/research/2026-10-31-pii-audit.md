## Proposed history rewrite

This is a destructive, force-pushing operation. It requires explicit operator approval; nothing below has run.

1. Freeze pushes and tell every collaborator. Decide between the two GitHub options:
   - **Ask GitHub support to purge** the old commits, PR refs and cached views after the force-push. Keeps issues and
     PRs, but relies on support and leaves a window where old commit URLs resolve.
   - **Delete and recreate the private repository**, then push the rewritten mirror. Deterministic removal of old
     objects, PR refs and Actions metadata, but loses issues, PRs, stars and settings. For a private repository with
     no forks and no published packages, this is the cleaner option unless the PR history is worth keeping.
2. Work from a fresh mirror, not the working clone:

   ```sh
   git clone --mirror git@github.com:<current-owner>/dashhaus.git dashhaus-rewrite.git
   cd dashhaus-rewrite.git
   # git-filter-repo is not part of git; install it first (brew install git-filter-repo, or pipx install).
   ```

3. Write `replacements.txt` (file contents), `messages.txt` (commit messages) and `mailmap.txt`. The replacement
   file must keep the two false positives intact, so use boundaries: `regex:(?<![A-Za-z])Nova(?![A-Za-z])==>Nova`,
   `regex:(?<![A-Za-z])nova(?![A-Za-z])==>nova`, then `novaSleep==>novaSleep`, `Krystosterone==><public-owner>`,
   `/home/operator==>/home/operator`. `messages.txt` replaces the owner handle in the merge subjects and the
   brief body. `mailmap.txt` maps `Krystian Czesak <krystianczesak@gmail.com>` to the public maintainer identity
   (a GitHub noreply address is fine); filter-repo rewrites both author and committer from it.
4. Drop the private critique folder from every commit and rewrite:

   ```sh
   git filter-repo --force \
     --replace-text ../replacements.txt \
     --replace-message ../messages.txt \
     --mailmap ../mailmap.txt \
     --path-glob '.impeccable/*' --invert-paths
   ```

   Use the same two boundary rules on the commit-message file; do not run a bare `s/nova/nova/g`.
5. Re-add the remote, push every ref, and retire the old clone directory:

   ```sh
   git remote add origin git@github.com:<public-owner>/dashhaus.git
   git push --force --mirror origin
   ```

   `--mirror` includes `main`, `dx/guarantee` and `ci/gate-speedups`; delete branches that are no longer wanted
   before pushing. Re-clone everywhere; do not pull into a clone that still has the old objects.
6. Purge locally and on GitHub: `git reflog expire --expire=now --all && git gc --prune=now --aggressive` in the
   mirror and in every kept clone; `gh cache delete --all --repo <owner>/dashhaus`; delete Actions artifacts and
   old workflow runs if the repository is kept; ask support to purge if that option was chosen.
