## Proposed history rewrite

This section records the preparation. The executed route was delete-and-recreate, so the force-push commands below
were not used. The mirror was still used as the clean source for the recreated repository.

1. Work from a fresh mirror, not the working clone:

   ```sh
   git clone --mirror git@github.com:Krystosterone/dashhaus.git dashhaus-rewrite.git
   cd dashhaus-rewrite.git
   # git-filter-repo is not part of git; install it first (brew install git-filter-repo, or pipx install).
   ```

2. Write `replacements.txt` (file contents) with boundary-safe rules. Keep the two false positives intact:

   ```text
   regex:(?<![A-Za-z])<former-child>(?![A-Za-z])==>Nova
   regex:(?<![A-Za-z])<former-prefix>(?![A-Za-z])==>nova
   <former-prefix>Sleep==>novaSleep
   <former-prefix>SleepMode==>novaSleepMode
   chambre_<former-prefix>==>nursery
   <former-child>'s room==>Nursery
   <home-path>==>/home/operator
   ```

   Replace the placeholder lines with the exact old strings in the local, untracked replacement file; do not commit
   that file. Do not include `Krystosterone` or `krystianczesak@gmail.com`: the operator chose to keep them.

3. Drop the private critique folder from every commit and rewrite:

   ```sh
   git filter-repo --force \
     --replace-text ../replacements.txt \
     --path-glob '.impeccable/*' --invert-paths
   ```

   No `--replace-message` or `--mailmap` is needed for this route: the owner handle and identity are retained, and
   no commit message names the child.

4. Re-add the remote **only after approval**, then force-push every ref:

   ```sh
   git remote add origin git@github.com:Krystosterone/dashhaus.git
   git push --force --mirror origin
   ```

   `--mirror` includes `main`, `dx/guarantee` and `ci/gate-speedups`; delete branches that are no longer wanted
   before pushing. Re-clone everywhere; do not pull into a clone that still has the old objects.

5. If a push is ever approved, purge locally and on GitHub: `git reflog expire --expire=now --all && git gc
   --prune=now --aggressive` in the mirror and in every kept clone; `gh cache delete --all --repo
   Krystosterone/dashhaus`; delete Actions artifacts and old workflow runs if the repository is kept; or delete and
   recreate the repository. Without that step the old child-name objects remain reachable.
