import { Card, CardGrid } from "@astrojs/starlight/components";

<CardGrid>
  <Card title="Two skins, one house" icon="seti:image">
    Orb is soft and glanceable. Field is a hardware panel with keys, faders and a dark screen. Both draw the same
    entities, so you can switch between them or run both.
  </Card>
  <Card title="Lays out your house" icon="rocket">
    With no layout written, each dashboard groups your lights, climate, covers, sensors and alarm by area. Write YAML
    when you want your own order.
  </Card>
  <Card title="Edit in Home Assistant" icon="pencil">
    Each dashboard is one Lovelace card. Change its layout in Home Assistant's code editor: the preview redraws as you
    type, and every mistake is listed with a fix.
  </Card>
  <Card title="Build your own skin" icon="puzzle">
    The entity models, Home Assistant hooks and card frame are packages. A new skin brings only its drawing: hand an
    agent a screenshot and [Build a skin](/dashhaus/start/build-a-skin/) does the rest.
  </Card>
</CardGrid>
