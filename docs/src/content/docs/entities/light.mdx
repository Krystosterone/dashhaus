One `light.*` entity: whether it's on, how bright, and its warmth or colour when it has them.

## Quick example

<Example file="entities/light/LightButton.tsx" />

The hook maps the raw light into a `LightEntity` and builds its actions. A tap calls `light.toggle`; the button changes when Home Assistant reports the new state.

## Component

`<HaLight>` is `useHaLight` as a component that draws nothing of its own. It takes every option of the hook as a
prop, and hands the hook's result to its child function. Use it where hooks can't go, such as one per item of a list.

<ApiMembers from="@dashhaus/core" name="HaLight" only={["entityId", "children"]} />

## Hook

<ApiSignature from="@dashhaus/core" name="useHaLight" />

It reads the light, its area from Home Assistant's registries, and today's history from the recorder.

Every action on an unavailable entity is reported to `onActionError` as `unsupported` and never sent.

## Every light

Hooks can't be called in a loop, so a list renders one headless component per entity. The selector returns a string: `useHaSelector` re-renders only when its value changes, and a string of ids changes only when an entity comes or goes. Lists skip each item's history read with `loadHistory={false}`.

### Dim it and set its warmth

`onKelvinChange` and `onColorChange` are only there when the light can use them, so test the handler, not the light's name or model.

### How long it's been on today

<Example file="entities/light/OnToday.tsx" />

`history.onMinutes` counts today's minutes on, the current hour included. `history.samples` has one value per hour for a strip of your own.
