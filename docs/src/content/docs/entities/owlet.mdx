## Component

`<HaOwlet>` is `useHaOwlet` as a component that draws nothing of its own. It takes every option of the hook as a
prop, and hands the hook's result to its child function. Use it where hooks can't go, such as one per item of a list.

<ApiMembers from="./api-types" name="HaOwletProps" only={["entityId", "children"]} />

## Hook

<ApiSignature from="@dashhaus/core" name="useHaOwlet" />

It reads the sleep state, every companion, its area and today's history of sleep, heart rate and oxygen. `staleAfterMinutes` (default 3) is how long without a changed reading before `live` turns false.

The readings are read-only; the base station is the one thing to switch.

## Every sock

Hooks can't be called in a loop, so a list renders one headless component per entity. The selector returns a string: `useHaSelector` re-renders only when its value changes, and a string of ids changes only when an entity comes or goes. Lists skip each item's history read with `loadHistory={false}`.
