One `humidifier.*` entity, a dehumidifier included: on and off, a target humidity and its modes.

## Quick example

<Example file="entities/humidifier/Humidity.tsx" />

`kind` is `dehumidifier` when Home Assistant's `device_class` says so: it dries to its target instead of adding moisture.

## Component

`<HaHumidifier>` is `useHaHumidifier` as a component that draws nothing of its own. It takes every option of the hook as a
prop, and hands the hook's result to its child function. Use it where hooks can't go, such as one per item of a list.

<ApiMembers from="@dashhaus/core" name="HaHumidifier" only={["entityId", "children"]} />

## Every humidifier

Hooks can't be called in a loop, so a list renders one headless component per entity. The selector returns a string: `useHaSelector` re-renders only when its value changes, and a string of ids changes only when an entity comes or goes. Lists skip each item's history read with `loadHistory={false}`.
