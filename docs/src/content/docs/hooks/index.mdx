## Pictures

A camera's still or a player's artwork is the entity's own picture. `useHaPicture` gives it as a URL your page can
load, resolved against your Home Assistant, and nothing while the entity is unavailable, so a past frame never reads
as now. `usePicture`, from `@dashhaus/core/hooks`, loads it only once its box is on screen and the page is visible,
refreshes a still only while both stay true, and keeps the last frame up while the next one loads. `useHaMoreInfo`
opens Home Assistant's own dialog for the entity, which plays a camera's live stream; outside Home Assistant it gives
nothing, so open your own details instead.

## Below the hooks

Each entity hook is three pure functions you can call without React or a store, for a host that keeps Home
Assistant's state its own way: a mapper from raw state to the model, history parsing, and an action factory over
anything with a `callService`. For a light:

<ApiSignature from="@dashhaus/core" name="lightFromHass" />
<ApiSignature from="@dashhaus/core" name="lightHistoryFromHass" />
<ApiSignature from="@dashhaus/core" name="createLightHandlers" />

Every kind has the same three: `climateFromHass` and `createClimateHandlers`, `coverFromHass` and
`createCoverHandlers`, and so on; a reading has no handlers.
