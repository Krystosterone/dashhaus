## Below the hooks

Each entity hook is three pure functions you can call without React or a store, for a host that keeps Home
Assistant's state its own way: a mapper from raw state to the model, history parsing, and an action factory over
anything with a `callService`. For a light:

<ApiSignature from="@dashhaus/core" name="lightFromHass" />
<ApiSignature from="@dashhaus/core" name="lightHistoryFromHass" />
<ApiSignature from="@dashhaus/core" name="createLightHandlers" />

Every kind has the same three: `climateFromHass` and `createClimateHandlers`, `coverFromHass` and
`createCoverHandlers`, and so on; a reading has no handlers.
