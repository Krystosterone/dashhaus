Everything here happens in Home Assistant, in your browser. There's nothing to install on your computer, no token to
copy and no file to upload. You need an administrator account.

<Aside type="caution" title="Dashhaus is in beta">
  Try each lock, alarm panel and cover once while you can see it, and read a release's notes before you update.
  [What that means](/dashhaus/intro/#beta), and how to tell us how it went.
</Aside>

## Install

<Steps>

1. Open Dashhaus in your Home Assistant:

   <LinkButton href="https://my.home-assistant.io/redirect/hacs_repository/?owner=Krystosterone&repository=dashhaus&category=plugin" icon="external">
     Open in Home Assistant
   </LinkButton>

   On Home Assistant 2026.11 or newer this opens the built-in **Marketplace**. On an older version it opens
   **HACS**, which you [install first](https://www.hacs.xyz/docs/use/). If you're asked whether to add the repository
   as a custom one, say yes; its type is **Dashboard**.

2. Press **Download** (or **Install**) and keep the defaults. Home Assistant copies Dashhaus into its `www` folder and
   registers it as a dashboard resource.

3. Reload the browser tab, so Home Assistant loads the new resource.

4. Open **Settings → Dashboards** and press **Add dashboard**.

5. Under **Community dashboards**, pick **Dashhaus**, keep or change its name and icon, and press **Create**. It
   appears in the sidebar.

</Steps>

The dashboard has a tab for each look, **Orb** and **Field**, each laid out from your house.

## What you get

- One dashboard, with a tab for each look. Each tab is the look's whole page, on the automatic layout: every supported
  entity in a row per area, kept up to date as you add devices.
- It follows Home Assistant's light or dark mode, and Dashhaus as it updates: the dashboard stores only
  `strategy: type: custom:dashhaus`, never a copy of the layout.
- Nothing is created behind your back and no other dashboard is touched. Delete the dashboard like any other.

### Choose the look, and a wall panel

To keep one look, or set up a wall panel, open the dashboard and its **Edit dashboard** (the pencil, or **⋮**). In the
**Edit dashboard** dialog, **⋮ → Edit in YAML**, add to the strategy and save:

<Example file="install/strategy.yaml" title="One look, for a wall panel" />

| Key | What it does |
| --- | --- |
| `skin` | `orb`, `field`, or a list of them in tab order. Every look when left out. |
| `viewing` | `near` (default): a phone or tablet in the hand. `far`: a wall panel read from across the room. |
| `theme` | Orb's colours: `home-assistant` (default, follows its dark mode), `auto`, `light` or `dark`. |
| `finish` | Field's finish: `home-assistant` (default), `auto`, `alloy` or `black`. |
| `title` | The title each page prints in its header. `Home` by default. |

To lay out your own cards and rows instead, take control of the dashboard (the same dialog's **⋮ → Take control**),
which keeps each look's card as it is now, and edit it; [Lay it out in YAML](/dashhaus/start/yaml/) shows how. A
dashboard you take control of no longer follows the strategy.

## If something goes wrong

If **Add dashboard** has no **Dashhaus** under Community dashboards, or a dashboard says `Custom element doesn't
exist` or `Timeout waiting for strategy element`, Home Assistant hasn't loaded Dashhaus yet. Reload the tab. If that
doesn't help, open **Settings → Dashboards → ⋮ → Resources** and check there's a JavaScript module at
`/local/community/dashhaus/dashhaus.js`.

Community dashboards are listed from Home Assistant 2026.5. On an older version, or a Home Assistant that keeps its
dashboards in YAML, create a dashboard yourself and give it the strategy as its whole configuration:
`strategy: { type: custom:dashhaus }`. Or give a **Panel** view one look's card, which is just its type and a title:

<Aside title="The setup card is deprecated">
  Earlier versions asked you to add a **Dashhaus setup** card and press **Create dashboards**. That card still works,
  and the dashboards it made keep working, but you no longer need it: use **Add dashboard → Dashhaus** instead.
</Aside>

## Update

The Marketplace (or HACS) tells you when there's a new version. Update it there, then reload the tab. Your dashboards and
their layouts are kept.

<Aside title="Pick one way to install">
  Install from the Marketplace or [from the command line](/dashhaus/start/deploy/), not both. Each registers its own
  copy, and the page would load Dashhaus twice.
</Aside>

## Ask an assistant to do it

An assistant that can use your browser can follow this page on its own. Give it the page's address, or this:

```text
Install the Dashhaus dashboards in my Home Assistant. I'm signed in as an administrator.
1. Open https://my.home-assistant.io/redirect/hacs_repository/?owner=Krystosterone&repository=dashhaus&category=plugin
   and download Dashhaus (type: Dashboard; add it as a custom repository if asked). Keep the defaults.
2. Reload the browser tab.
3. Settings → Dashboards → Add dashboard → under Community dashboards, pick "Dashhaus" → Create.
4. Open the new Dashhaus dashboard from the sidebar and check its Orb and Field tabs draw.
   Don't change any other dashboard, and never ask me for a password or token.
```
