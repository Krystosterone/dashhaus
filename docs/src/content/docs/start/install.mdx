Everything here happens in Home Assistant, in your browser. There's nothing to install on your computer, no token to
copy and no file to upload. You need an administrator account.

<Aside type="caution" title="Dashhaus is in beta">
  Try each lock, alarm panel and cover once while you can see it, and read a release's notes before you update.
  [What that means](/dashhaus/intro/#beta), and how to tell us how it went.
</Aside>

## Install

<Steps>

1. Open Dashhaus in your Home Assistant:

   <LinkButton href="https://my.home-assistant.io/redirect/hacs_repository/?owner=Krystosterone&repository=dashhaus&category=plugin" icon="external">
     Open in Home Assistant
   </LinkButton>

   On Home Assistant 2026.11 or newer this opens the built-in **Marketplace**. On an older version it opens
   **HACS**, which you [install first](https://www.hacs.xyz/docs/use/). If you're asked whether to add the repository
   as a custom one, say yes; its type is **Dashboard**.

2. Press **Download** (or **Install**) and keep the defaults. Home Assistant copies Dashhaus into its `www` folder and
   registers it as a dashboard resource.

3. Reload the browser tab, so Home Assistant loads the new resource.

4. Open **Overview**, then **⋮ → Edit dashboard → Add card**, search for **Dashhaus setup**, and save it. Any
   dashboard works; you'll remove the card afterwards.

5. In the setup card, leave a look checked if you want it: **Home (Orb)**, **Home (Field)** or both. Press **Create
   dashboards**.

6. Open each new dashboard from the card's links, or from the sidebar. If the sidebar doesn't show them yet, reload
   the page.

7. Remove the setup card when you're done. Keeping it is harmless: it never changes a dashboard that exists.

</Steps>

## What the setup card does

- It creates `/dashhaus-orb` and `/dashhaus-field`, each with one panel view holding its look's card, and adds them to
  the sidebar.
- Each dashboard starts on the automatic layout: every supported entity in a row per area, kept up to date as you add
  devices. [Lay it out in YAML](/dashhaus/start/yaml/) shows how to choose your own cards and rows.
- It never renames, overwrites or deletes a dashboard that already exists. A second press creates only what's missing.
- It only uses your own signed-in session to create the dashboards. Nothing leaves your Home Assistant.

## If something goes wrong

| The setup card says | What to do |
| --- | --- |
| Only an administrator can create dashboards | Sign in as an administrator and open the page again. |
| This Home Assistant manages its dashboards in YAML | Create the dashboard in your configuration yourself, give it a **Panel** view, and add the card below. |
| A dashboard was not created, with a reason | The others still were. Fix the reason and press Create again; it only creates what's missing. |

If the card picker has no **Dashhaus setup**, or a dashboard says `Custom element doesn't exist`, Home Assistant hasn't
loaded Dashhaus yet. Reload the tab. If that doesn't help, open **Settings → Dashboards → ⋮ → Resources** and check
there's a JavaScript module at `/local/community/dashhaus/dashhaus.js`.

## Update

The Marketplace (or HACS) tells you when there's a new version. Update it there, then reload the tab. Your dashboards and
their layouts are kept.

<Aside title="Pick one way to install">
  Install from the Marketplace or [from the command line](/dashhaus/start/deploy/), not both. Each registers its own
  copy, and the page would load Dashhaus twice.
</Aside>

## Ask an assistant to do it

An assistant that can use your browser can follow this page on its own. Give it the page's address, or this:

```text
Install the Dashhaus dashboards in my Home Assistant. I'm signed in as an administrator.
1. Open https://my.home-assistant.io/redirect/hacs_repository/?owner=Krystosterone&repository=dashhaus&category=plugin
   and download Dashhaus (type: Dashboard; add it as a custom repository if asked). Keep the defaults.
2. Reload the browser tab.
3. On Overview: ⋮ → Edit dashboard → Add card → "Dashhaus setup" → Save.
4. In that card, press "Create dashboards", then open "Home (Orb)" and "Home (Field)" from its links.
5. Remove the setup card. Don't change any other dashboard, and never ask me for a password or token.
```
