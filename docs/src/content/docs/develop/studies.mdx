A study is a skin an agent built, kept so you can see what Dashhaus makes and start from it. It is not finished or
polished, and it doesn't ship.

A study is a run: a fresh agent, given only the release packages, a picture or a description and a Home Assistant
to deploy to, builds a skin the way you would with [Build a skin](/dashhaus/start/build-a-skin/), then writes down its
design rules and every guess and dead end along the way. Each study is then kept in the repository like any skin: in
Storybook under **Studies**, with a Read me first page, its cards, dashboards, foundations and connected cards, and
checked like every skin so it keeps working.

Do what you want with them: take ideas, copy a part or a card, improve one, or build a skin of your own on top of it.
If you make one better, contributions back are welcome.

To run one, see [Cards and skins](/dashhaus/develop/cards-and-skins/#a-study). This list is built from the repository,
so every study appears here.
