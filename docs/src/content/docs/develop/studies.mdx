Studies are how we check that Dashhaus works for someone who isn't us. When the packages, the scaffolder or their
guides change, we hand a fresh agent the release packages, a picture or a description and a Home Assistant to deploy
to, and nothing else: no repository, no web, no help. It builds a skin the way you would with
[Build a skin](/dashhaus/start/build-a-skin/), and writes down every guess, retry and dead end along the way. That list
is the real result. Each item is something a guide left unsaid or a tool got wrong, and it becomes the next fix.

The skin is a by-product, and we keep it because it's too good to throw away. Each one lands in the repository like
any other skin: in Storybook under **Studies**, with a Read me first page, its cards, dashboards, foundations and
connected cards, and the same checks as every skin, so it keeps working as Dashhaus changes. None of them is finished
or polished, and none of them ships. A few were built inside the repository instead of from the packages; each one's
Read me first page says how it was made.

Do what you want with them: take ideas, copy a part or a card, improve one, or build a skin of your own on top of it.
If you make one better, contributions back are welcome.

To run one, see [Cards and skins](/dashhaus/develop/cards-and-skins/#a-study). This list is built from the repository,
so every study appears here.
