# Dashhaus 0.8.1

Status: written in its release PR, at the commit whose files [0.8.1.sha256](0.8.1.sha256) records. It

## Release page

Orb's and Field's cover cards now send a position once, when a drag, a tap or a held arrow key lets go, instead of on
every move. A generated skin records esbuild's install-script decision, so `npm install` prints no warning.
