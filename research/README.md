## Corrections

- **2026-10-21: history command.** The history slice added in `57cc8eb` (and the cover/toggle/alarm demos in `d87da9a`) called `recorder/history_during_period` with `entity_id` and parsed an array of `{ entity_id, state, last_changed }` records. That command does not exist: Home Assistant core registers `history/history_during_period` (and `history/stream`) in `homeassistant/components/history/websocket_api.py`, takes `entity_ids`, and replies with an object keyed by entity id holding compressed rows `{ s, a, lu, lc? }` with epoch-second times. Against a live instance every history read would be rejected as an unknown command and the Today strips would stay empty (inferred from core's command registry; not observed on a live instance). The tests passed only because the demo transport, fixtures and parser shared the invented shape. Fixed in [docs/home-assistant.md → History slice](../docs/home-assistant.md#history-slice), with a wire-shape fixture at `src/ha/fixtures/history_during_period.json`. Lesson: fixtures for a wire contract must come from the server's source or a capture, never from the parser they test.
